# Portfolio

macOS-inspired personal portfolio for Rajat Sharda.

**Live:** https://rajat-portfolio23.netlify.app/

## Frontend

From the `frontend/` directory:

1. Install dependencies with `npm install`
2. Start the dev server with `npm start`

Runs the React app (Create React App) locally.

## Backend (optional - Siri / NeMo)

See `backend_nemo/` for the NeMo Guardrails knowledge base and Siri assistant config.

## Notes

- Resume PDF: `frontend/public/resume.pdf`
- Projects: `frontend/src/apps/Safari.tsx`
- About / contact: `frontend/src/apps/Notepad.tsx`
